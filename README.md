# Superstore-Sales-analysis

📊 Project Overview

This project analyzes the Superstore sales dataset using Microsoft Excel to understand sales performance, profitability, customer segments, product categories, and regional trends.

The analysis focuses on identifying key business insights and patterns that can help in making better data-driven decisions.

🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Data Cleaning
* Data Analysis
* Charts & Visualizations
* Basic Excel Functions

🔍 Analysis Performed

* Analyzed overall Sales and Profit
* Compared performance across Product Categories and Sub-Categories
* Analyzed Regional and State-wise sales
* Studied Customer Segment performance
* Identified profitable and less profitable products
* Analyzed Sales and Profit trends
* Created summaries using Excel Pivot Tables and charts

📈 Key Insights

* Identified the categories and sub-categories contributing most to sales and profit.
* Compared regional performance to understand differences in sales and profitability.
* Analyzed customer segments to identify high-performing segments.
* Identified products and areas with lower profitability.
* Used visual analysis to understand important sales and profit patterns.

📁 Files Included

* Superstore_Sales_Analysis.xlsx — Excel workbook containing the dataset, analysis, and results.

🎯 Objective

The main objective of this project is to demonstrate practical Excel-based data analysis and business intelligence skills by converting raw sales data into meaningful insights.
